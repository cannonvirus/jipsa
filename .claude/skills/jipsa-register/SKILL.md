# jipsa-register

이름 하나로 프로젝트를 만들고, 있는 등록은 질문으로 고친다. 인자는 프로젝트 이름(영문 소문자, 숫자, 밑줄)과 `edit` 또는 `show`다(`고치기`, `보기`도 받는다).

- 인자가 없으면 `uv run jipsa registry show`로 목록을 보이고 `/jipsa-register <이름>` 쓰는 법 한 줄을 붙여 끝낸다. 묻지 않는다.
- `show`를 붙였으면 `uv run jipsa registry show <이름>`의 출력만 보이고 묻지 않는다.
- `edit`를 붙였으면 아래 "고치기"를 따른다. 없는 이름이면 출력의 "없다" 줄을 보이고 끝낸다.
- 이름만 있으면 아래 "새 프로젝트"를 따른다.

## 새 프로젝트

묻지 않고 이 폴더(jipsa 저장소)에서 명령 하나를 돌린 뒤 출력을 그대로 보이고 끝낸다. 되묻기, 확인, 칸 표, 저장 질문을 하지 않고 서브에이전트를 띄우지 않는다.

```
uv run jipsa registry new <이름>
```

- 폴더는 jipsa 저장소 바로 위 폴더 아래 `<이름>`이다. 없으면 만들고 git 첫 커밋까지 한다. 있으면 건드리지 않고 그 폴더를 등록한다.
- 나머지는 기본값이다. 종류 code, 우선순위 50, 작업자 claude, 자동 범위 "기능 브랜치 커밋까지. 원격 생성과 푸시 없음", 커밋 예, GPU 0, 읽기 금지 .env, 읽기 전용 CLAUDE.md와 AGENTS.md다.
- 잘못된 이름과 이미 등록된 이름은 명령이 "거절:" 한 줄로 끝낸다. 그 줄만 보이고 다시 묻지 않는다.
- 사용자가 이름과 함께 경로나 종류를 직접 말했으면 `'path=<경로>'`, `'kind=<종류>'`를 명령에 더한다. 경로를 주면 폴더를 만들지 않는다.
- 다음 일은 대시보드 TODO 탭에서 넣는다고 명령 출력이 알린다. 스케줄러는 다음 주기에 새 등록을 읽으므로 다시 띄우지 않는다.

## 고치기에서 지키는 규칙

- 질문은 한 번에 하나다. 질문마다 지금 값(없으면 기본값)을 보이고, 빈 답(엔터)은 그 값을 그대로 둔다. "그만"이라고 답하면 저장하지 않고 끝낸다.
- 잘못 답하면 까닭과 고를 수 있는 값을 보이고 한 번 다시 묻는다. 두 번째도 틀리면 그 칸은 지금 값으로 두고 다음 질문으로 넘어가며 끝 요약에 "건너뜀"으로 적는다. 값 검사는 저장 명령의 검사 동작(`check`, `--check`)에 맡기고 거절 문구를 그대로 까닭으로 보인다.
- 뜻이 분명해도 사람이 적지 않은 값을 스스로 고르지 않는다. "실험"처럼 영어 이름과 다르게 답하면 그렇게 읽어도 되는지 되묻는다.
- 환경 변수가 덮은 칸(`show` 출력에 "환경 변수가 앞선다"가 붙은 칸)은 묻지 않고 "환경 변수가 앞선다. .env를 고쳐야 바뀐다"고 알린다.
- 묻지 않은 칸은 기본값으로 둔다. 끝에 바뀐 칸만 표로 보이고 "이대로 저장할까"를 묻는다. 예라고 답할 때만 저장한다.
- 이 폴더(jipsa)에서 명령을 돌리고 서브에이전트를 띄우지 않는다. 설정 파일과 등록 toml을 직접 고치지 않고 명령으로만 쓴다. 쓰는 명령은 메인 세션 전용이다.
- 명령은 값마다 작은따옴표로 감싼다. 값 안의 작은따옴표는 셸에 맞게 바꾼다. PowerShell은 `''`처럼 두 번 겹치고, bash는 `'\''`로 쓴다.

## 고치기

`registry show`의 칸 19개를 표로 보이고 "고칠 칸 이름과 새 값을 적는다. 끝이면 끝"을 되풀이한다.

- 이름 칸은 "파일 이름이라 고치지 않는다"고 거절한다.
- 목록 칸(허용 폴더, 읽기 금지, 읽기 전용, 외부 읽기, 외부 금지, Ollama 모델)은 "더하기 값", "빼기 값"으로 받는다. 명령에는 `'칸+=값'`, `'칸-=값'`으로 넘긴다.
- 값을 비우면 그 키를 지워 기본값으로 돌아간다. 명령에는 `'칸='`으로 넘긴다.

끝이라고 하면 먼저 검사해 바뀐 줄의 전후를 보이고 저장을 묻는다.

```
uv run jipsa registry edit <이름> '<칸>=<값>' '<칸>+=<값>' --check
```

예면 `--check`를 뗀 명령을 돌리고 출력(바뀐 칸 수, 바뀐 줄 수)을 보인다. 주석과 키 순서는 명령이 지킨다. 고친 등록은 스케줄러가 다음 주기에 읽으므로 다시 띄우기를 묻지 않는다.

## 사용 예

```
/jipsa-register ocr_new
/jipsa-register ocr_new edit
/jipsa-register ocr_new show
```
