# auto

Auto 모드(Auto 절, 켜기와 끄기, Auto 끝 글)는 261029-jipsa-17에서 없어졌다. `jipsa auto`는 깨지지 않고 없어졌다는 안내와 지금 상태(동시 Cycle 수, 시킨 줄, 대기열)를 찍는다. `jipsa auto`(상태)는 0으로, 그 밖의 동작(on, off, add, top, rm)은 아무것도 바꾸지 않고 1로 끝난다.

## 절차

1. 사용자가 친 인자를 바꾸지 않고 그대로 넘긴다. 인자 전체를 작은따옴표 하나로 감싼다.
   - `/auto` → `uv run jipsa auto`
   - `/auto <동작> [인자]` → `uv run jipsa auto <동작> '<인자>'`
   - 인자 안의 작은따옴표는 PowerShell은 `''`, bash는 `'\''`로 쓴다.
2. jipsa 폴더에서 돌리고 출력 그대로를 사용자에게 보인다. 덧붙이는 설명은 없다.
3. 대신 다른 명령을 돌리지 않는다. 시키는 것은 사용자가 `/todo run`으로 한다.

## 바뀐 길

- Cycle 줄은 `/todo run <번호> [시작 HH:MM] [마감 HH:MM|+4h]`로 시킬 때 시작과 마감을 정한다. 시작을 적지 않으면 지금, 마감을 적지 않으면 시작 뒤 8시간이다. 대시보드 TODO 탭의 Cycle 줄 Do가 같은 칸을 펼친다.
- 일회성 줄은 `/todo run <번호>`로 바로 돈다. 시작 시각 예약은 받지 않는다.
- 동시 실행 수(Cycle 단계 합쳐 6개, 사용 창 비율로는 막지 않음)와 GPU, RAM 나눔, 대기열은 모드와 무관하게 스케줄러가 맡는다.
- 마감이면 돌던 단계를 마치고 마감 결과지를 쓴 뒤 줄을 할 일로 돌린다. 다시 시키면 멈춘 자리부터 잇는다(판정까지 마친 회차면 다음 회차, 아니면 그 회차의 남은 단계). 멈추기는 `/todo stop <번호>`, 마감 고치기는 `/todo until <번호> <HH:MM|+2h>`다.
- 옛 할 일 파일의 `## Auto` 절 줄은 할 일로 읽고, 파일을 다시 쓸 때 할 일 절로 합친다.
- Slack은 밤사이 끝난 Cycle을 아침 한 번(기본 07:30, JIPSA_MORNING_AT) 모아 보낸다.
