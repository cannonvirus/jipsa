# jipsa-cleanup

기록 보관 기한 3개와 중간 산출물 정리를 묻는다. 정리를 켤 때만 2개를 더 묻는다. 인자는 없거나 `show`(`보기`)다. `show`는 `uv run jipsa settings show --skill cleanup` 출력만 보이고 묻지 않는다. 이 스킬은 값만 정하고 파일을 옮기거나 지우지 않는다.

## 같이 지키는 규칙

- 질문은 한 번에 하나다. 질문마다 지금 값(없으면 기본값)을 보이고, 빈 답(엔터)은 그 값을 그대로 둔다. "그만"이라고 답하면 저장하지 않고 끝낸다.
- 잘못 답하면 까닭과 고를 수 있는 값을 보이고 한 번 다시 묻는다. 두 번째도 틀리면 그 칸은 지금 값으로 두고 다음 질문으로 넘어가며 끝 요약에 "건너뜀"으로 적는다. 값 검사는 저장 명령의 검사 동작(`check`, `--check`)에 맡기고 거절 문구를 그대로 까닭으로 보인다.
- 뜻이 분명해도 사람이 적지 않은 값을 스스로 고르지 않는다. "실험"처럼 영어 이름과 다르게 답하면 그렇게 읽어도 되는지 되묻는다.
- 환경 변수가 덮은 칸(`show` 출력에 "환경 변수가 앞선다"가 붙은 칸)은 묻지 않고 "환경 변수가 앞선다. .env를 고쳐야 바뀐다"고 알린다.
- 묻지 않은 칸은 기본값으로 둔다. 끝에 바뀐 칸만 표로 보이고 "이대로 저장할까"를 묻는다. 예라고 답할 때만 저장한다.
- 이 폴더(jipsa)에서 명령을 돌리고 서브에이전트를 띄우지 않는다. 설정 파일과 등록 toml을 직접 고치지 않고 명령으로만 쓴다. 쓰는 명령은 메인 세션 전용이다.
- 명령은 값마다 작은따옴표로 감싼다. 값 안의 작은따옴표는 셸에 맞게 바꾼다. PowerShell은 `''`처럼 두 번 겹치고, bash는 `'\''`로 쓴다.

## 질문

`uv run jipsa settings show --skill cleanup`으로 지금 값을 읽어 "기록 보관과 정리 설정이다. 지금 값: ..."으로 시작한다.

1. 실행 기록을 월별 보관함으로 옮기기까지 며칠 둘까? 키는 `JIPSA_RETAIN_RUN_DAYS`다.
2. 세션 기록과 일회성 폴더는 며칠 둘까? 키는 `JIPSA_RETAIN_OTHER_DAYS`다.
3. 월별 보관함은 며칠 뒤 지울까? 키는 `JIPSA_RETAIN_ARCHIVE_DAYS`다.
4. 끝난 작업의 브라우저 프로필, 임시 DB 사본 같은 중간 산출물을 하루 한 번 휴지통 폴더로 옮길까? 예, 아니오. 키는 `JIPSA_RUNS_CLEAN_ON`이다.
5. (4번이 예일 때만) 마지막 활동에서 며칠 지나야 옮길까? 키는 `JIPSA_RUNS_CLEAN_DAYS`다.
6. (4번이 예일 때만) 옮겨 둘 휴지통 폴더는? {date}는 옮긴 날짜로 바뀐다. 키는 `JIPSA_RUNS_CLEAN_TRASH`다. 드라이브가 없으면 저장 전에 알린다.

답마다 `uv run jipsa settings check '<키>=<값>'`로 검사한다. 정리 종류와 최소 크기, 지킬 이름, 답한 작업 보호 일수는 묻지 않는다. 기본값을 쓰고 환경 변수로만 바꾼다.

## 저장

바뀐 칸만 전후로 보이고 "이대로 저장할까?"를 묻는다. 예면 바뀐 칸을 쓴다.

```
uv run jipsa settings set '<키>=<값>' '<키>=<값>'
```

## 다시 띄우기

저장한 값은 스케줄러와 대시보드를 다시 띄워야 반영된다. 저장을 끝내면 `uv run jipsa settings show --skill cleanup` 둘째 줄의 실행 중 작업 수를 보이고 "지금 다시 띄울까"를 묻는다. 기본값은 아니오다.

- 예이고 실행 중 작업이 0개면 `uv run jipsa settings restart`를 돌리고 출력을 보인다.
- 실행 중 작업이 있으면 "다시 띄우면 그 작업이 끊긴다"고 먼저 알린다. 그래도 예라고 답할 때만 `uv run jipsa settings restart --force`를 돌린다.
- 아니오면 "다음에 스케줄러가 다시 뜰 때 반영된다"고 알린다. 돌고 있는 작업은 전 값으로 끝난다고 덧붙인다.

## 사용 예

```
/jipsa-cleanup
/jipsa-cleanup show
```
