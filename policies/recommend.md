# 추천안으로 가도 되는 결정의 범위

jipsa가 시작한 작업자가 사람에게 묻지 않고 추천안으로 갈 수 있는 결정이다. 모드와 무관하다. 승인한 규칙이 생기면 한 줄씩 더한다.

## 추천안으로 간다

- 브랜치 안의 코드 변경 방식. 구현 방법, 함수 배치, 이름, 주석.
- 초안의 구성과 문장. 분량과 순서.
- 조사 범위와 출처 선택. 로컬 자료에서 무엇을 먼저 볼지.
- 허용 폴더 안에서 되돌릴 수 있는 파일 추가와 수정.
- 실험 스크립트의 실행 순서와 결과 정리 형식.

## 확인 필요로 넘긴다

- 금지 경로(읽지 않음, 읽기만, 생성물)에 쓰기가 필요한 것.
- 외부 쓰기. 발행, 푸시, 전송, 주문.
- 의존성 예외. torch 계열 변경, 기존 패키지 버전 변경.
- 완료 기준을 다르게 해석해야만 끝낼 수 있는 것.
- 삭제나 이동이 기능 브랜치 밖에 미치는 것.
- 비용이나 시간이 총 상한을 넘을 것이 확실한 것.
