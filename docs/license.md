# 라이선스

이 저장소는 MIT 라이선스다. 전문은 저장소 최상위의 `LICENSE`에 있다. 저작권자는 커밋 작성자와 같은 GitHub 아이디 cannonvirus다.

단순하고 널리 쓰이는 허용형 라이선스라서 개인용 도구를 공개하는 데 맞아 MIT를 골랐다.

## 함께 쓰는 외부 자료

- 의존 패키지(rich, psutil, requests, python-dotenv)는 각자의 라이선스를 따른다. 목록은 `uv.lock`에 있다.
- 대시보드 글꼴은 저장소에 넣지 않는다. `web/fonts/README.md`의 명령으로 각 배포처에서 받으며 글꼴마다 SIL Open Font License 등 자체 라이선스를 따른다.
